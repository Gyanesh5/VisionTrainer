# 0004 - 切片标注归属采用完整落入规则（而非 SAHI 式裁剪）

Status: accepted（2026-10-30，两轮 grilling 用户裁决：重叠要做、空片默认丢弃、残缺默认丢弃；本 ADR 裁的是重叠之下「形状与片的归属语义」）

切片（Tiling）把托管数据集按网格切成小图生成新托管数据集。重叠边带启用后，一个跨界形状与多个片都有交集，归属语义有两条成熟路线，本平台取 **A**：

- **A. 完整落入才归属（采用）**：形状外接矩形完整落入某片才归属该片并平移坐标；不裁剪、不产生残缺标注。重叠的职责是让跨界目标总能在邻片完整出现（重叠率 ≥ 最大目标尺寸即零丢失）。无裁剪形态的形状（circle=圆心+半径、rotation=旋转框）与可裁形状（rectangle/polygon）天然共享同一条规则，无特判分支。比片还大、任何片都无法完整容纳的目标在 dry-run 预览红字警示、计数入汇总——不悄悄裁成碎块。
- **B. SAHI 裁剪归属（拒绝）**：与片有交集即候选、几何裁剪到片界、裁剪后可见面积占比 ≥0.1 保留（`sahi/slicing.py` 的 `min_area_ratio` 语义）。永不丢目标，但：残缺标注进训练与「避免模型学到半圆歧义」的既有裁决相反；circle/rotation 格式上裁不了（labelme 无残缺圆/任意多边形 rotation），必须特判成第二套规则；大目标被切成多片碎块且各片重复。SAHI 该语义为推理切片评测设计（保住部分可见目标的检测完整性），不是训练数据构造目标。

## 边界规则（同轮裁决，一并记录）

- **空片**（无归属标注的片，无论有无残影）默认丢弃，开关保留为负样本。
- **残影**：形状与片有交集而未完整归属 → 该片带残影标记，审查判定不继承、回待审（复审）；片内目标全部完整归属或零目标 → 继承源图判定（经 `write_review` 重算 shapes 哈希——直接拷贝 `vt_review` 键会因哈希不符被判「已修改」）。
- **切分**：切片集出生按源图分组随机重新切分（同源小图永不跨侧，防 val 泄漏；分层按源图主类）。
- 网格推进与 SAHI 同构：步长=片尺寸−重叠、每轴末片回退保整片（不产窄条碎片片）。

## Consequences

- 重叠率是唯一丢失控制参数：丢弃率偏高时用户调网格/重叠率，而不是开关裁剪。
- 「残缺保留开关」从设计里移除（被重叠率取代）；比片大的目标是数据问题（回源头修），不是切片参数问题。
- 派生自切片集的 val 指标与整图口径不可直接对比（目标相对尺寸放大、重叠片重复采样）——跨数据集对比时须知此语义。
