# 0009 - 托管数据集拥有真源与类别表

Status: accepted（2026-11-03，源自 dataset-training-rehome 02/06 号票）

托管数据集不再注册一个由平台与 X-AnyLabeling 共同猜测所有权的原始目录：平台在数据集目录内拥有 `source/` 真源目录，并以 `classes.txt` 为类别唯一真源。新建与加图通过拷贝或移动把图片及标注纳入平台；类别追加、改名、重排、删除只从平台发起。这样消除双 master 漂移，并让未登记类别在进入训练前被阻断，而不是在转换时静默丢弃。

## Considered Options

- **继续注册外部标注目录**：无需搬移文件，但目录所有权、加图与删除语义始终分裂，拒绝。
- **X-AnyLabeling 拥有类别表**：桌面端操作更自由，但平台无法保证类别 id、训练映射与校验账目一致，拒绝。
- **只靠 `--validatelabel exact` 防表外类别**：06 号原型证明它只是拦新标的软守卫，存量 JSON 与 Label Manager 可绕过，不能替代平台入口校验。

## Consequences

- 类别改名是继 ADR 0003 审查键、ADR 0005 几何正规化之后的第三条平台标注写路径，必须备份、原子写并继承审查判定；平台仍不提供通用标注编辑或破坏性形状转换。
- 平台与 X-AnyLabeling 通过单实例协议同步打开、换集、类别表与重扫；协议同步不能替代磁盘真源与平台校验。
- 真源搬移与类别所有权变更是 v1.4 一次性迁移的一部分，不保留旧目录双写或兼容层。
