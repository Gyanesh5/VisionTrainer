# 0005 - 标注自动修复写回真源（平台写路径第二条）

Status: accepted（2026-10-30 用户裁决：平台可处理的问题给一键修复按钮、修复写回标注文件、这类问题不再判「有问题」；修复范围前五类与审查判定继承为用户未逐项裁决时的默认，已显式标注可翻案；第六类折线闭合为同日追加裁决——「你自己把他闭合不就修复了」）

## 背景与裁决

ADR 0003 首次放宽「JSON 只读」，但白名单仅 `checked`/`vt_review` 两键——标注**内容**（shapes）始终是 X-AnyLabeling 的人的领地，平台只读。校验报告对越界/无效多边形等问题只给「回 XAL 重画」的指引。

2026-10-30 用户裁决：其中**平台可确定性处理**的问题（几何正规化，不改标注意图）应提供一键修复并写回源标注文件，且不再占用校验红灯。本 ADR 把这条新写路径的边界钉死。

## 修复范围（六类，全部确定性正规化）

| 问题码 | 修复动作 | 备注 |
| :-- | :-- | :-- |
| out_of_bounds | 全点钳制回画布 | detect/segment/obb/pose 通用；与转换期 clamp 同口径，修的是真源而非派生 |
| polygon_invalid | shapely `make_valid` | **翻 R6 初版「不自动 make_valid」裁决**；自交修复后可能分裂成多个多边形（守恒不丢目标） |
| obb_invalid | 凸包环重排 | 仅四点凸位置的乱序可修；共线/零面积/内点（凸包为三角形）仍归人工 |
| drop（折线误画） | shape_type `linestrip`→`polygon` | 仅 segment（polygon 只在 seg 模式被转换器接受，detect/obb 翻转了照样丢弃故不标可修）；点一字不动、labelme 多边形本就是隐式闭合环；**闭合边是推断的**（标注员没画那笔），2026-10-30 用户裁决可接受；两点的 `line` 与闭合后无面积者（开放曲线）仍归人工 |
| keypoints_invalid | 负坐标钳回 0 | 贴画布边 |
| orphan_json | 移入数据集侧隔离区 | **不删除**可找回；隔离区在源目录外——源目录内的子目录会被扫描 rglob 重新捞起（backup/duplicates 踩过的坑） |

不进自动修复：bad_json（不可解析无从修）、unreadable_image（文件级）、no_matching_shape / unknown_labels（语义判断）、几何退化类丢弃（degenerate_box/invalid_circle/too_few_points/pose 无框组——信息已丢失）。这些保留逐图修法指引（红）。

## 写回约束

- **原子写**复用 ADR 0003 的 tempfile+fsync+os.replace；**只动 shapes 的几何点**，label/group_id/flags 及全部其他顶层键（含 `checked`/`vt_review`）原样保留。
- **修复前整文件备份**到 `<数据集目录>/autofix/<时间戳>/backup/`（按源目录相对路径镜像）；孤儿落同运行目录 `orphans/`。
- **修复以源目录现状为准**（apply 时重扫重判），不信任旧报告快照——报告可能滞后于手工改动。
- 逐文件失败（bad_json 等）跳过不中断整体，进 skipped 账目（零静默不变：修不了的照旧在报告里）。

## 审查判定继承（默认裁决，可翻案）

修复改了 shapes 内容，双指纹机制会判「已修改」回待审。默认**继承判定**：`vt_review.shapes_hash` 按修复后内容重算，状态/理由/判定时间不动——几何正规化不改变标注意图，与切片一致性继承（ADR 0004）同款语义。反方案「回待审复审」被否：钳制/重排这类确定性变换再过一遍人眼是纯成本。若修复涉及 make_valid 分裂这类形态变化较大的场景在实际使用中暴露误继承，收紧为「分裂类回待审」即可。

## 校验口径三变化

1. problems 各项对可修复问题带 `fixable: true`（obb 仅乱序为 true；drop 仅 segment 可闭合折线为 true），报告新增 `fixables` 计数；problems 全量保留（守恒账目不变）。
2. `ok` 只看不可自动修复项——fixable 问题不再判「有问题」；训练提交确认门只对需人工项亮红。
3. 审查可疑度「校验」来源不计 fixable 项（一键可修不配抢占审查前排）。

## Consequences

- 平台对标注真源从「只写两键」变为「可写几何正规化」——写路径仍窄（六类谓词 + 原子写 + 备份），语义字段碰不到。折线闭合严格说改的是一个语义字段（shape_type），但几何点不动、意图不变（封闭形状画错工具），与 make_valid 同属形态正规化档。
- 概览与校验页签问题区只展开需人工项；可修复项以琥珀计数条 + 一键按钮呈现（确认门复述计数后执行）。
- 修复后自动增量重转派生 + 全量重校验（丢弃账目随之重算，新丢弃集合出现会重新要求确认——诚实入账）。
- R6 初版「不自动 make_valid」裁决作废，以本 ADR 为准。
