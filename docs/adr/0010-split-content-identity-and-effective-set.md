# 0010 - 切分以划分内容为身份并冻结实效集

Status: accepted（2026-11-03，源自 dataset-training-rehome 03/08 号票）

切分从数据集的「活跃清单」改为训练表单内创建、跨 Task 复用的持久化实体，uid 只由 train/val 成员划分哈希决定，创建参数与血缘仅作溯源。出队时再按当前磁盘缺失与排除日志计算实效集，并把实效名单冻结进 Run 快照。划分身份因此不被改标、排除恢复或参数记账扰动，同时历史 Run 仍保留完整可复现输入。

## Considered Options

- **参数寻址**：seed/ratio/stratify 不能唯一决定划分，且改标可能意外换 uid，拒绝。
- **活跃清单与切回**：排除、恢复、加图都制造版本，历史膨胀且 Task 的可比性依赖隐式指针，拒绝。
- **Task 钉住派生目录**：把成员与内容耦合并复制目录树；缺失成员和排除恢复难以表达，拒绝。

## Consequences

- 同切分 uid 才承诺 val 一致与指标可比；Agent 复训和续训必须钉原 uid，不能跟随「最近」。
- 排除与恢复不再生成切分；实效 train 或 val 为空拒训，其余缺图与排除只剔除并提示。
- 旧 Run 的可用性通过 v1.4 迁移时改写快照获得，新代码不保留旧清单或默认格式兼容分支。
