# 0007 - 审批门 human-on-the-loop 化（工具分级 + 审批四态 + 预算熔断）

Status: accepted（2026-10-31 用户确认整体方案；依据 `.scratch/agent-redesign/` 调研板块三一手核实结论）

## 背景与裁决

原审批门：轮与轮之间的人工放行检查点，manual（默认）/ auto 两档。往智能化自动化方向重设计时，每轮等人放行成为自动化瓶颈；但砍掉审批（全自动无人闭环）被调研证据否决：MLE-Dojo 实证 8 个前沿 LLM「自主长程规划与复杂错误修复仍是显著短板」；MLE-bench 榜单因评测完整性违规除名两条提交；LangChain 2026 调研（n=1340）：57% 受访者 agent 已上生产，59.8% 认为 human review 对高风险场景 essential——业界事实是**人从每步审批退到高危节点与审计**，分级单位是「每工具/每动作」而非「每 agent 档位」。

## 决策

审批门从「每轮固定人工放行」升级为「**策略可配 + 工具分级 + 预算熔断 + 全量审计**」的 human-on-the-loop：

- **自主档位二值**：autonomous（默认：动作工具护栏内直通 + 桌面通知 + 全量审计 + 随时可停）/ supervised（每轮人工放行，原 manual 语义保留为保守选项）。原 auto 档被 autonomous 吸收。
- **审批四态**（扩自原 continue/stop 二态）：放行 / **改后放行**（修改方案后放行）/ 拒绝本轮方案 / 终止循环。改后放行对齐 PydanticAI `ToolApproved(override_args)` 与 weco revise 语义。
- **工具分级审批策略**（与 ADR 0006 工具面三级配套）：只读直通+审计；动作护栏内直通（supervised 档升审批）；关键（数据侧建议/部署推荐）**任何档位都人工确认**——不可逆/外向动作恒过人。
- **批量预审**：睡前把整夜轮计划排队、一次放行、循环整夜执行——审批门的 UX 升级而非拆门。
- **三层预算熔断**：轮数上限（已有）+ 单轮运行时长上限（新增，防「合法但极慢」参数组合）+ 累计 token/成本上限（新增）；触顶优雅停 + 通知。
- **策略文件**：调参/审批/预算策略抽成用户可编辑文件，循环代码冻结（autoresearch program.md 思路）。
- **审计升级**：agent_decisions 从轮级决策扩展为工具调用轨迹级归档。
- 状态机扩态：轮级 waiting_approval → 工具级 pending 审批队列；fail-closed（参数缺失/非法 JSON 直接要人）；审批状态持久化跨重启恢复。

## 不变项

不可逆动作（部署回注、删改数据）恒人工确认；终止只认数字；paused 等人不烧卡；审批等待不占训练队列。

## 被否方案

- **全自动无人闭环**：无人值守价值已由 autonomous 档拿走，剩余增量 = 无人值守做不可逆动作，期望值为负（见背景证据）。
- **维持每轮 manual**：与「智能化自动化」方向正面冲突，降级为 supervised 可配档。
