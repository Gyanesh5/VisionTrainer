# 0011 - 投影与格式适配分层

Status: accepted（2026-11-03，源自 dataset-training-rehome 04 号票）

真源标注先经格式无关的「投影」变为任务规范几何，再由格式适配器编码为训练或外部导出格式。投影是唯一的形状守恒与丢弃账目点；适配器声明支持矩阵、实际 class_map、负样本策略和入口形态，并对声明支持的任务无损。这样避免每种格式各写一套几何规则，也避免 X-AnyLabeling 转换器的静默丢弃进入训练链路。

## Considered Options

- **直接复用 X-AnyLabeling 格式转换器**：其依赖 PyQt6/cv2，且存在静默跳过与守恒账目缺口，不符合平台环境及零静默约束，拒绝。
- **每种格式独立解释真源形状**：实现直接，但校验、新鲜度门与导出会产生多套守恒口径，拒绝。
- **平台提供破坏性形状改写**：可让真源迎合单一格式，但越出既有窄写白名单并改变人的标注意图，拒绝。

## Consequences

- 可投影的跨任务形状只产生信息级 lint，真正不可投影者才属于 task_mismatch。
- 校验、出队新鲜度门与导出共用投影；格式池只保存适配器编码结果。
- COCO/VOC 导出适配器由平台实现；X-AnyLabeling 仅作为几何分支与格式惯例的参考，不进程内 import。
