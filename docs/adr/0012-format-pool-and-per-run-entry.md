# 0012 - 格式池与逐 Run 训练入口

Status: accepted（2026-11-03，源自 dataset-training-rehome 04 号票）

派生标签只依赖真源、类别表与格式，不依赖切分，因此每个数据集每种格式只维护一份可删重建的格式池；切分差异下沉为每个 Run 出队时生成的训练入口与实效集清单。该布局取代 per-切分整树，既满足 Ultralytics 的 images/labels 路径约束，也避免重切、排除和恢复时复制或重建整棵目录。

## Considered Options

- **per-(切分, 格式) 完整目录树**：语义直观，但同一标签被重复保存，切分操作与派生刷新耦合，拒绝。
- **直接以 source/ 训练**：会把派生 txt 逼进真源目录，且无法隔离格式与类别映射，拒绝。
- **所有 Run 共享固定 data.yaml**：历史入口会随最近切分变化，快照不可复现并继承绝对路径迁移问题，拒绝。

## Consequences

- 格式池是缓存，没有「重建派生标注」用户动作；版本戳或类别表哈希变化时出队整池重建，单图标签逐字节核对后重写。
- 每个 Run 的入口、实效集、格式元数据与实际 class_map 一并归档；错误分析和部署回查类别读快照而非当前 classes.txt。
- classify 使用逐 Run 类目录树例外；第二训练后端仍出界，但后端到格式的绑定已有明确扩展点。
