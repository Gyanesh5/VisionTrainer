# 0016 - 联动契约 v1.0 定稿：标注复核回归训练平台侧与控制面废除

Status: accepted（2026-11-19，随联动契约 v1.0 定稿记账；推理端侧翻案归其仓 ADR 修订/新立，随其实施票落地）

## Context

[ADR 0015](0015-vision-monitor-linkage.md) 定训练平台侧配套时，职责边界沿用推理端仓 ADR-0014 当时的定案：轻量标注留在监控侧（操作员复核预标注初稿）；交互协议沿用其仓 ADR-0019 的三角拉取式（工位出站训练请求到专机、专机回调拉样、工位轮询回传权重）。

2026-11-19 联动契约 v1.0（[docs/linkage-contract.md](../linkage-contract.md)）定稿为两系统对接唯一权威契约，其中两处推翻上述定案：

1. **人工判定归训练平台侧**：契约 §4.5 规定导出包不得携带审查状态键（checked/vt_review）——复核是训练平台侧职责；推理端退役复核 UI 与轻标注工作台（其仓实施票 #146）。
2. **控制面废除**：契约 §5.1 不设训练请求协议，推理端不向训练平台发起任何写请求；其已实装的训练请求出站通道与模型回传编排退役，改接模型发布拉取（契约 §5.4）。

本 ADR 记训练平台侧的翻案链与对齐决定。

## Decision

1. **契约 v1.0 为联动域唯一权威 spec**：导出包格式（manifest schema_version=1 字段冻结）、样本拉取面、状态回写面、模型发布面与共享口径以契约为准，仓内冲突描述以契约为准。词汇对齐表（契约 §3）为 GLOSSARY 联动域改写基准：对端角色词=推理端/训练平台，参照实现专名 vision-monitor 只出现在参照说明处（GLOSSARY 联动域首注）。
2. **标注复核归位训练平台侧（翻案链闭合）**：人工判定环节定在训练平台，由既有标注审查工作流承担（[ADR 0003](0003-review-state-in-annotation-json.md) 的 vt_review 状态机不变）；预标注初稿按未判定初稿入库，确认、修正、丢弃全部走平台审查流。翻案链：复核外置（2026-11-16 推理端仓 ADR-0014 同日首决「纯推理、复核全部外置」）→ 同日翻案回归监控侧（理由=交互面留在数据源头、轻标注直产训练平台兼容格式）→ 2026-11-19 契约定稿再翻案回归训练平台侧（职责单一化：推理端只推理与采集，契约 §2；复核与数据集组织、训练节奏同侧自理，契约 §5.1）。「轻量标注」词条自 GLOSSARY 退役，契约词=标注复核。
3. **控制面废除**：不设训练请求协议。训练的发起、数据集组织、复核与训练节奏全部由训练平台自理；平台不开入站控制面（从未实装训练请求受理），推理端不开出站写请求。推理端仓 ADR-0019 的「三角拉取式交互协议」与训练请求最小信封被契约 §5（无控制面+双向只读拉取面）取代。
4. **延续定案**：模型发布（0015 Decision 1）、模型页与 Run 权重真源（0015 Decision 2）、样本回流内置导入源（0015 Decision 3/4）、状态回写全链（0015 Decision 5）延续，契约 §5.2–5.4 与 §6 为其跨系统面。样本状态机收缩为四态交付账本（采集 → exported → ingested → trained，契约 §6.1），推理端侧复核三态退役；trained 回写口径=导出清单 ∩ 实效集（契约 §6.2，与 docs/api.md 票 124 段既有实现同口径）。
5. **与推理端仓 ADR 的合龙**：其 ADR-0014 的拓扑（工位 Jetson + 训练专机同产线局域网）与「边缘设备不开入站写面」边界维持有效，复核位置与模型回传路线部分由本 ADR 与契约翻案；其 ADR-0019 的模型域工作台壳体与「模型族、人工切换、一键回滚」语义维持（改由模型发布拉取台承载），训练请求信封与训练任务视图退役。推理端侧翻案记账归其仓（0014/0019 修订或新 ADR）。

## Consequences

- GLOSSARY 联动域角色词化随本票落地：轻量标注退役、标注复核按契约词重定义，新增推理端/预标注初稿/样本状态机词条；主动学习环、导出包、模型发布、工位词条去专名化。
- 契约 §10 偏差登记驱动后续实施：训练平台侧 classify 消费面（#131）与拉取恢复（#132）待建；推理端侧状态机收缩、拉取台、重置动作归其仓票。
- spec.md 经查无联动旧语义残留（轻量标注/监控侧/训练请求零命中），联动功能细节以契约与 docs/api.md 为准。
- v3 张力挂账不变（0015 Decision 7）：推理端 v3 全自动与本仓「全自动无人闭环不做」（[ADR 0006](0006-agent-base-and-decision-providers.md)）的冲突，契约 §8 预留专门裁决门。
